Continuous Integration (CI)

Implemented in this Project

The software practice where developers frequently commit code to a shared repository. Every push triggers an automated build and test runner to detect syntax issues, missing assets, and broken links immediately.

  • ✔ Early bug detection before merging
  • ✔ Consistent automated validation
  • ✔ Eliminates “works on my machine” issues
🚀

Continuous Delivery (CD)

Next Step in DevOps

An extension of CI where validated code is automatically packaged and prepared for release. Deployment to a production or staging server is ready to trigger with manual one-click approval.

  • • Ensures every tested build is deployable
  • • Manual human gatekeeper decides release timing
  • • Not implemented in this baseline assignment
🌍

Continuous Deployment (CD)

Advanced Automation

The most automated stage where every change that passes all CI tests is deployed directly to end-users in production without any manual intervention.

  • • Zero human intervention after git push
  • • Requires rigorous, mature test coverage
  • • Not implemented in this baseline assignment
ⓘ
Academic Project Scope Notice: This project strictly implements Continuous Integration and Automated Testing. It automates verification and quality gates using GitHub Actions. It intentionally does not perform automated web hosting deployment, cloud hosting, or database operations, keeping the architecture 100% free, reproducible, and beginner-friendly.
